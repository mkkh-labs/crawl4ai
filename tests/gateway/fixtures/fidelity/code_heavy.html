Deploying the gateway

Run the container behind the private network:

# create the network first
docker network create automation_internal

docker compose up -d crawl4ai

Then verify the effective configuration:

def check(config):
    if config["limits"]["wall_clock_s"] == 0:
        raise ValueError("unbounded deadline")

    return {
        "ok": True,
        "depth": config["limits"]["max_depth"],
    }
